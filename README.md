# KrishiMitra

A single-file working prototype of an AI-powered farmer assistant.

## Run in VS Code

1. Extract/open this folder in VS Code.
2. Open `index.html`.
3. Right-click `index.html` and choose **Open with Live Server** if you have the Live Server extension.
4. Or simply double-click `index.html` to open it in a browser.

No Python, Node.js, MongoDB or API key is required for this demo.

## Included

- Farmer profile
- AI-style farming assistant
- Government schemes
- Market-price cards
- Crop image upload + demo analysis
- Browser voice input
- Consultation report
- LocalStorage persistence
- Responsive mobile/desktop design

## Important

Market prices and crop analysis are demonstration data/results. For a real deployment, connect verified government/market data and a real image model/API.
